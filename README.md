# Digital Clock

A simple and responsive **Digital Clock** that displays the current time in real time.

## ✨ Features

* Real-time clock display
* Automatic time updates
* 12/24-hour time format
* Clean and responsive interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 Purpose

This project was created to practice **JavaScript date and time functions** and real-time DOM updates.
